The Problem

Vector databases are passive warehouses.

Pinecone, Milvus, Qdrant, Weaviate — they all do the same thing: store vectors and return results. They don't understand context. They don't learn from usage. They can't protect themselves from adversarial inputs. And they certainly don't execute decisions.

In a world of autonomous AI agents, your data infrastructure needs to be as intelligent as the models it serves.

Quick Start

Three commands. Infinite cognition.

Terminal 
# Build & run
cargo build --release
./target/release/kce-server

# Or use Docker
docker compose up --build
Semantic Query 
curl -X POST http://localhost:3000/query \
  -H "Content-Type: application/json" \
  -d '{
    "text": "rust memory safety patterns",
    "top_k": 5,
    "filters": {}
  }'
Execute Intent (mRNA) 
curl -X POST http://localhost:3000/action \
  -H "Content-Type: application/json" \
  -d '{
    "context_id": "ctx-abc123",
    "intent": "risk_eval",
    "params": {}
  }'
# → {"action":"risk_eval","result":{"risk_score":0.72,
#    "recommendation":"APPROVE_WITH_CONDITIONS"},
#    "execution_ms":2.3}
